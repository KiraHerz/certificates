# Сертификаты Per Aspera

Генератор сертификатов выпускников Per Aspera Ad Astra. Выберите направление, впишите имя и фамилию, укажите дату и скачайте готовый PDF.

## Что можно настроить

- **Направление:** Mission to Web, Mission to Web + 3D, Mission to AI, Mission to UX/UI
- **Имя и фамилия** выпускника
- **Дата выдачи:** месяц и год
- **Язык сертификата:** русский или английский
- **«завершил / завершила»** для русской версии
- **Особые достижения** со значком (только Mission to AI)

## Как пользоваться

Откройте сайт по ссылке GitHub Pages этого репозитория, заполните поля и нажмите «Скачать PDF».

## Как изменить программы

Все тексты сертификатов (модули, проекты, инструменты, часы, цвета плашек) лежат в `index.html` в объекте `DIRS`. Подписи, лицензия и названия разделов — в объекте `COPY`.

## Шрифты

Макет свёрстан на SF Pro Display. Если шрифт не установлен на устройстве, подставляется Inter.
